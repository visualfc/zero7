# ZERO7 使用指南

ZERO7 是一款中文语音中国象棋应用。本文介绍当前版本已经提供的功能和常用操作，适合第一次使用的用户。

## 1. 开始使用

### 1.1 启动应用

开发环境需要 Node.js 22 或兼容版本，并准备好 Pikafish 引擎。首次运行：

```bash
npm install
cp .env.example .env
npm run dev
```

启动后：

- 电脑访问 `https://localhost:5173/`。
- 桥接服务运行在 `http://127.0.0.1:8787/`。
- 手机和电脑连接同一 Wi-Fi 后，使用终端输出的局域网 HTTPS 地址访问。

浏览器需要允许麦克风权限。语音功能必须在 HTTPS 安全上下文中使用；本地开发可以按照 README 中的 `mkcert` 步骤安装证书。

### 1.2 首页

首页提供三个主要入口：

- **人机对战**：从标准开局开始与零七对弈。
- **杀棋训练**：练习一步杀至 N 步杀题目。
- **残局训练**：练习六类残局和引擎应手。

首页的“今日三小关”会从杀棋题库中稳定随机选择三题。同一天重复打开时，选择保持一致。完成数量显示在首页进度区域。

桌面端侧边导航和移动端底部导航都包含：**对战、训练、残局**。点击零七标志可以返回首页。

## 2. 人机对战

### 2.1 开始对局

点击首页的“人机对战”，用户执红，零七执黑。页面会显示棋盘、棋谱、语音区域和对战操作。

右侧可以选择三档棋力：

- 入门
- 初级
- 中级

如果 Pikafish 不可用，应用会使用基础 AI 继续提供对局；局面分析功能需要 Pikafish。

### 2.2 走棋方式

可以使用两种方式走棋：

1. **点击棋盘**：点击己方棋子，再点击目标位置。
2. **中文语音**：按住“按住说走法”按钮，说完后松开；也可以按住空格键说话，松开空格键提交识别结果。

语音可以说“炮二平五”“马八进七”等中文棋谱。应用会先通过本地规则引擎检查走法，合法后才更新棋盘并请求零七应手。

用户走棋后，零七会按照当前棋力思考并落子。语音播报和引擎走棋异步执行，语音播放卡住时不会阻塞对局。

### 2.3 棋谱和操作

- 左侧“对局棋谱”显示当前对局的中文棋谱。
- 最近一步会显示走子路径和相应动画。
- **悔棋**：撤销当前对局中最近的用户和零七走法。
- **重开一局**：恢复标准开局并清除当前棋谱。
- **认输**：结束当前对局并记录认输状态。
- **返回当前局面**：查看棋谱中的历史局面后，返回正在进行的局面。

切换到训练、残局或首页后再回到对战，当前棋盘和棋谱会保留在本次会话中。

### 2.4 局面分析

Pikafish 可用时，点击“局面分析”展开分析面板。面板显示：

- 红方和黑方胜率估计。
- 推荐走法。
- 推荐走法的目的说明。

分析是异步请求。正在分析时可以等待结果，分析失败时会显示不可用提示；这不会改变当前棋局。

## 3. 杀棋训练

### 3.1 选择题目

进入“杀棋训练”后，先选择杀棋类型，再选择题号：

- 一步杀
- 二步杀
- 三步杀
- 四步杀
- N 步杀

题目编号按类型分组。页面会显示题目标题、难度、分类和“红方先行”或“黑方先行”。棋谱显示在棋盘左侧。

### 3.2 完成题目

按照页面显示的先行方走棋。可以点击棋盘，也可以使用语音输入。用户走出合法着后，零七会使用 Pikafish 计算应手；训练不会只根据固定答案判断成功。

- 形成真实绝杀后，显示“绝杀！”。
- 黑方无将军且没有合法着时，显示“困毙杀！”。
- 被将军且将或帅的退路被己方棋子封住时，显示“闷杀！”。
- 其他合法走法会保留棋局，并继续请求引擎应手。

用户可以随时点击：

- **重新练习**：恢复当前题目的初始局面。
- **跳过这题**：直接进入下一题。
- **挑战下一关**或**继续下一题**：完成后进入下一题。

### 3.3 提示

点击“再给我一点提示”逐级查看提示。提示最多三阶段，只提供思路和语音朗读，不会自动替用户走棋，也不会直接完成题目。

## 4. 残局训练

### 4.1 选择残局

进入“残局训练”后，可以按残局类型和题号选择题目。当前分类包括：

- 车类残局
- 马炮残局
- 炮类残局
- 马类残局
- 兵类残局
- 仕相残局

题目下方会显示精确的子力对型和“红方先行”或“黑方先行”。残局棋谱显示在棋盘左侧。

### 4.2 走棋和讲解

残局支持点击走棋、中文语音走棋和完整棋谱记录。每一步合法走棋后，零七会使用引擎应手；语音播报不会阻塞黑方走棋。

点击“展开引擎讲解”查看当前局面的：

- 推荐走法。
- 局面评价。
- 讲解文字。

展开状态下，用户走棋、零七应手或切换题目后，讲解会根据最新局面自动更新。点击“收起引擎讲解”停止自动更新。点击讲解旁的音量按钮可以朗读当前推荐内容。

## 5. AI 复盘

### 5.1 打开复盘

在“人机对战”页面底部点击“AI复盘”。复盘打开后：

- 人机对战暂时停止走棋。
- 暂停“轮到你继续走棋”的回合提醒。
- 原人机棋局保留，点击“返回对战”即可恢复。

当前版本的复盘使用经典完整棋局数据。复盘不会显示没有可靠来源支持的胜负结果。

### 5.2 搜索和选择经典棋局

在“搜索赛事或棋手”输入关键词，可以搜索赛事、中文棋手名或来源原名。选择列表中的棋局后，应用才加载该棋局的完整棋谱。

列表只展示已确认中文姓名的棋局。选中棋局后，左侧显示完整中文棋谱，中间显示当前局面。

### 5.3 回放控制

复盘控制栏提供：

- **开局**：回到第 0 步。
- **上一步**：退回一步。
- **下一步**：前进一步。
- **终局**：跳到最后一步。
- **自动播放**：每 5 秒前进一步并异步朗读中文棋谱。

也可以直接点击左侧棋谱中的任意一步跳转。全局分析产生的关键步显示在棋盘右侧，点击关键步可以跳转到对应局面。

### 5.4 当前局面分析

点击“展开局面分析”后，应用会分析当前复盘位置并显示：

- 红方和黑方胜率估计。
- 实战着。
- 实战着的推测目的。
- 从第 3 步开始，当推荐着与实战着不同时，显示推荐着和推荐目的。

切换复盘步骤后，展开的分析会自动更新。点击“收起局面分析”可以停止显示分析结果。

### 5.5 全局分析

点击“分析关键步”开始全局分析。分析分为快速扫描和候选关键步深度复核两个阶段，内部预算控制在约 30 秒内。完成后，关键步按棋谱顺序排列在棋盘右侧，并标出局势变化和红方胜率变化。

全局分析运行时可以等待完成。切换棋局或返回对战会取消当前全局分析任务。

## 6. 语音操作

### 6.1 支持的常用指令

首页：

- “开始训练”
- “开始人机对战”
- “我可以说什么”
- “返回首页”

训练页：

- “提示”或“再给我一点提示”
- “重新训练”
- “下一关”
- “返回首页”

人机对战页：

- 中文棋步，例如“马二进三”
- “悔棋”
- “重开一局”
- “认输”
- “打开局面分析”
- “关闭局面分析”
- “推荐一步”
- “返回首页”

复盘状态下：

- “上一步”
- “下一步”
- “返回当前局面”

说“我可以说什么”或“帮助”，应用会根据当前页面播报可用指令。

### 6.2 语音失败时

- 识别到当前局面不能走的棋步：不会落子，并提示重新说合法走法。
- 没有识别成棋步或指令：提示“没听明白，请重新说”。
- 连接失败：页面显示错误，可以重新按住语音按钮。
- 浏览器不允许麦克风：检查浏览器权限，并确认使用 HTTPS 地址。
- 语音播放失败：棋局仍然继续，可以使用点击操作完成走棋。

悔棋、重开和认输等会影响对局状态的操作需要先说“确认”或“取消”。

## 7. 常见问题

### 棋盘可以显示，但语音不能使用

确认浏览器地址是 `https://`，已允许麦克风权限，并且电脑或手机可以连接本地桥接服务。HTTP 页面通常无法使用麦克风。

### Pikafish 显示不可用

确认 Pikafish 可执行文件和 NNUE 权重位于配置路径，或者设置：

```dotenv
PIKAFISH_PATH=/absolute/path/to/pikafish
PIKAFISH_MODEL=/absolute/path/to/pikafish.nnue
```

然后重启桥接服务，并检查：

```bash
curl http://127.0.0.1:8787/api/pikafish/status
```

基础人机对战仍可能继续运行，但局面分析、训练验证和残局讲解需要 Pikafish。

### 切换页面后棋局是否会丢失

人机对战棋局、棋谱和 AI 复盘步骤会保存在当前浏览器会话中。关闭浏览器或清除会话存储后，状态可能会重置。

### 经典棋局加载很慢

经典棋局列表先加载元数据。只有选择具体棋局后才加载完整棋谱；首次启动时 SQLite 数据库也可能需要初始化。
