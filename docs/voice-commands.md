# 零七全局语音指令设计

## 1. 目标

将语音输入从“只识别棋步”扩展为全局可用的语音指令入口。用户可以在首页、训练和人机对战场景中，用相同的按住识别、松开完成方式操作应用。

全局语音不增加独立按钮，首页使用空格触发。按下空格建立连接，持续按住，松开空格完成识别。训练页和人机对战页保留页面内语音按钮，同时支持空格。

每条指令使用一次灵矽短连接。按下时建立连接，松开时完成识别，识别结果处理后立即断开，应用不维持语音长连接。

## 2. 指令模型

解析器位于 `src/voice-command.ts`，将识别文本转换为结构化的 `VoiceCommand`：

```ts
type VoiceCommand =
  | { type: 'move'; text: string }
  | { type: 'battle.start'; level?: '入门' | '初级' | '中级' }
  | { type: 'battle.undo' }
  | { type: 'battle.restart' }
  | { type: 'battle.resign' }
  | { type: 'training.start' }
  | { type: 'training.next' }
  | { type: 'training.restart' }
  | { type: 'training.hint' }
  | { type: 'review.previous' }
  | { type: 'review.next' }
  | { type: 'review.exit' }
  | { type: 'analysis.show' }
  | { type: 'analysis.hide' }
  | { type: 'analysis.recommend' }
  | { type: 'help' }
  | { type: 'confirm' }
  | { type: 'cancel' }
  | { type: 'unknown'; text: string }
```

解析器只负责识别意图，不负责判断当前页面能否执行，也不直接修改棋局。

## 3. 页面指令

### 首页

```text
开始训练
开始人机对战
返回首页
我可以说什么
```

### 训练页

```text
提示
再给我一点提示
重新训练
下一关
返回首页
我可以说什么
```

棋步仍然交给训练规则处理。只有匹配当前关卡的合法答案才会完成关卡。

### 人机对战页

```text
马二进三
悔棋
重开一局
认输
打开局面分析
关闭局面分析
推荐一步
返回首页
我可以说什么
```

棋步必须通过当前局面的合法走法校验。非法棋步不会落子，也不会触发 AI 评论。


## 4. 上下文路由

同一语音内容由当前页面和状态决定含义：

| 指令 | 首页 | 训练页 | 人机对战 |
| --- | --- | --- | --- |
| 下一步 | 无操作 | 下一关 | 无操作 |
| 重新开始 | 无操作 | 重新训练 | 重开一局 |
| 返回 | 首页 | 首页 | 首页 |
| 提示 | 帮助说明 | 训练提示 | 帮助说明 |

路由顺序：

1. 处理确认或取消。
2. 处理全局命令，例如帮助和返回首页。
3. 处理当前页面命令。
4. 将 `move` 交给当前页面的规则处理器。
5. 无法识别时播报“没听明白，请重新说”。

## 5. 高风险操作确认

悔棋、重开一局和认输会改变或结束当前对局。语音识别到这些指令时，先记录待确认动作并提示：

> 请说确认或取消。

用户说“确认”后才执行，用户说“取消”则清除待确认动作。页面点击操作可以继续使用现有按钮。


## 6. 语音反馈

- 合法棋步：播报当前走法，然后按对战时序处理对方应手；正常应手不重复提示“轮到你继续走棋”。
- 红方 1 分钟没有动作：才提示“轮到你继续走棋”；如果处于将军状态，提示“将军，请先应将”。
- 非法棋步：播报“这步棋现在不能走，请重新说当前局面可以走的走法”。
- 非棋步文本：播报“没听明白，请重新说”。
- 帮助：根据当前页面播报可用指令。
- 连接失败：显示错误并要求重新按住语音按钮。
- HTTP 非安全上下文：提示使用终端显示的 HTTPS 地址。

## 7. 生命周期和并发

- 按下按钮或空格后建立连接并开始录音。
- 松开后完成录音。
- 每次会话只消费一个识别结果。
- 识别结果到达后断开识别连接。
- 页面切换、重开和返回首页时取消未完成语音会话。
- 对局思考期间忽略棋步指令。
- 过期 AI 请求不能覆盖新局面。
- 同一页面不能同时运行两个语音会话。

## 8. 开发约束

新增全局指令时需要同时更新：

1. `src/voice-command.ts` 的类型和解析规则。
2. 当前页面的上下文执行器。
3. `src/voice-command.test.ts` 的解析测试。
4. `src/App.test.tsx` 的端到端交互测试。
5. `README.md` 的用户可见指令说明。
6. 本文的指令表和时序说明。

运行检查：

```bash
npm run lint
npm test
npm run test:coverage
npm run build
```
