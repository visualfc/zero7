# 小象棋伴

面向 6～10 岁儿童的语音象棋闯关应用原型。项目通过短时闯关、分级提示和儿童化反馈，帮助孩子学习观察棋局和表达走法。

## 当前功能

- 中文儿童象棋首页与每日三关
- 可点击操作的中国象棋棋盘
- 模拟语音走棋流程
- 三层渐进式提示
- 闯关成功反馈和智慧星奖励
- 成长页与个人页
- 桌面端、平板和手机响应式布局

## 本地运行

要求安装 Node.js 22 或兼容版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可体验。

## 常用命令

```bash
npm run dev      # 启动开发服务器
npm run build    # 类型检查并构建生产版本
npm run lint     # 运行代码检查
npm test         # 运行自动化测试
npm run preview  # 预览生产构建
```

## 交互说明

在首页点击“开始今日挑战”进入第一关。可以通过两种方式完成挑战：

1. 点击红炮，再点击黑车；
2. 点击“按下说走法”，体验模拟语音识别和走棋。

“再给我一点提示”会逐级给出方向、棋子和完整走法。
