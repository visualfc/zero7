# 零七 ZERO7

零七是一款面向 6～10 岁儿童的 AI 语音象棋伙伴应用。项目通过短时闯关、分级提示和儿童化反馈，帮助孩子学习观察棋局和表达走法。

## 当前功能

- 中文儿童象棋首页与每日三关
- 可点击操作的中国象棋棋盘
- 灵矽实时语音识别与对话状态
- 浏览器麦克风采集与 `16 kHz PCM16` 音频流
- 灵矽凭证服务端代理，凭证不会进入浏览器
- 三层渐进式提示
- 闯关成功反馈和智慧星奖励
- 成长页与个人页
- 桌面端、平板和手机响应式布局

## 配置灵矽

### 1. 准备设备

在[灵矽控制台](https://xrobo.qiniu.com/)创建智能体并绑定一个设备标识。桥接服务需要与该设备对应的 `Device-Id` 和 WebSocket Token。

推荐通过官方 OTA 接口动态获取短期 Token：

```bash
cp .env.example .env
```

编辑 `.env`：

```dotenv
LINXI_DEVICE_ID=AA:BB:CC:DD:EE:FF
LINXI_USE_OTA=true
```

如果已有 WebSocket Token，也可以直接配置：

```dotenv
LINXI_DEVICE_ID=AA:BB:CC:DD:EE:FF
LINXI_USE_OTA=false
LINXI_TOKEN=设备鉴权令牌
LINXI_WS_URL=wss://xrobo-io.qiniuapi.com/v1/ws/
```

`.env` 已被 Git 忽略。请勿把 Token、API Key 或其他凭证提交到仓库。

### 2. 配置智能体

建议在灵矽控制台中将智能体设置为“小象教练”，并加入以下约束：

```text
你是面向 6～10 岁儿童的小象棋教练。回答简短、友好，每次只说一个重点。
当前关卡中，孩子需要说出“炮五进五”，用红炮吃掉正在将军的黑车。
鼓励孩子观察棋盘，不批评孩子，不提供与儿童象棋无关的内容。
```

## 本地运行

要求安装 Node.js 22 或兼容版本。

```bash
npm install
npm run dev
```

`npm run dev` 会同时启动：

- 网页开发服务器：终端显示的 Vite 地址；
- 本地灵矽桥接服务：`http://127.0.0.1:8787`。

浏览器会请求麦克风权限。点击“按下说走法”开始录音，说完后再次点击，灵矽返回识别文本并驱动棋局。

## 交互说明

在首页点击“开始今日挑战”进入第一关。可以通过两种方式完成挑战：

1. 点击红炮，再点击黑车；
2. 点击“按下说走法”，对麦克风说“炮五进五”，说完后再次点击。

“再给我一点提示”会逐级给出方向、棋子和完整走法。
